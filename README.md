# SunStack — pitch-deck website

A single-page, scroll-snap slide deck introducing **SunStack**: an Australian marketplace
that turns rooftop-solar surplus into sovereign AI compute. Built for a university
senior-management panel. Zero-build, vanilla HTML/CSS/JS — nothing to compile.

## View locally

It is a static site. The simplest way to serve it:

```bash
# from this directory (website/)
python3 -m http.server 8080
# then open http://localhost:8080
```

You *can* just double-click `index.html`, but a local server is recommended so the
self-hosted fonts and the demo video load correctly (some browsers block those over `file://`).

## Presenting / controls

Each slide is a full-viewport tile with CSS scroll-snap. Navigate with:

- **Next:** `↓` · `→` · `Space` · `PageDown`
- **Previous:** `↑` · `←` · `PageUp`
- **Jump to ends:** `Home` (first) · `End` (last)
- **Jump anywhere:** click a dot on the right-edge rail
- **Demo video:** click it (slide 11) to play full screen; `Esc` closes it

Motion respects `prefers-reduced-motion` — with it on, animations are disabled and the
deck falls back to normal scrolling; all content stays fully readable.

## Editing content

Everything lives in three files:

- `index.html` — all slide copy, as **20 `<section class="tile">` blocks** (one per slide).
  This is the only file to touch for wording/number changes.
- `assets/css/styles.css` — design tokens: the amber brand colours, type scale, layout.
- `assets/js/deck.js` — behaviour: keyboard nav, dot rail, reveal-on-scroll, lightbox.

## Regenerating images

The illustrations in `assets/img/` come from OpenAI **gpt-image-2**. The script is
idempotent — it only fills in **missing** images by default.

```bash
python3 tools/generate_images.py                 # generate any missing images
python3 tools/generate_images.py --force cover-hero   # redo one (by name)
python3 tools/generate_images.py --force all     # redo everything
```

It reads `OPENAI_API_KEY` from the **parent** `../.env` (i.e. `../.env`, never committed).
**This calls a paid API — regenerate selectively.** Product screenshots (`assets/shots/`),
logos, fonts, and the demo video are checked in and are not generated by this script.

## Deploy (GitHub Pages)

The site uses **relative paths** and a `.nojekyll` file, so it works whether Pages
serves it at an org root or under a project subpath.

```bash
git init && git add -A && git commit -m "site: SunStack pitch deck"
git branch -M main
git remote add origin git@github.com:DataCenterBehindMeter/sunstack.github.io.git
git push -u origin main
```

Then in the repo: **Settings → Pages → Deploy from a branch → `main` / root**.

The resulting project-site URL is
**https://datacenterbehindmeter.github.io/sunstack.github.io/** — the relative paths
make that subpath work. (For the clean org-root URL, the repo would instead need to be
named `datacenterbehindmeter.github.io`.)
