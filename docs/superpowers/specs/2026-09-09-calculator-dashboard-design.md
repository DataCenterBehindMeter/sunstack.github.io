# Calculator dashboard

Approved direction: a light SunStack dashboard with a dark equipment enclosure.

The calculator opens with five financial headline cards. A two-column workspace places the rig assembler and device catalog beside scenario, model, assumptions, and business controls. Below, a complete allocation of cloud-equivalent spend and an operating-hours sensitivity chart explain the annual results. Sources and exports remain available below the charts.

The rig uses an expandable shelf enclosure, physical device-family SVG illustrations, numbered bays, empty slots, and orthogonal cables to a PAIR controller. Illustrations represent hardware families; desktop GPU costs still include the host. Addition/removal works with pointer and keyboard, with focus retained. The enclosure adapts to two columns on phones and expands for large rigs.

All results derive from SunStackEngine. The allocation includes platform costs and explicitly reports losses when positive allocations exceed cloud spend. Sensitivity varies only activeHours from 0 to 24; lines show homeowner net and operator margin, including negative values, with a zero axis and the current selection marked. Accessible tables expose exact chart values.

Only calculator HTML, calculator CSS/JS, dedicated calculator illustrations, calculator tests, and these calculator documents are in scope. No shared stylesheet, deck file, runtime dependency, economic assumption, or deployment change. Preserve engine purity, global APIs, relative URLs, script dependency order, responsive layouts, reduced motion, source links, and live slider DOM identity.
